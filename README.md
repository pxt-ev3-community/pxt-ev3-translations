## Mirror of Microsoft MakeCode translations for LEGO MINDSTORMS EV3

This repository contains automatically updated mirror of the MakeCode
translation files pertaining to the pxt-ev3 project.

The translations are maintained on crowdin: https://crowdin.com/editor/makecode

They are downloaded through Microsoft's API. Example URL:

https://makecode.com/api/translations?lang=de&filename=ev3/infrared-sensor-strings.json
